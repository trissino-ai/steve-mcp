This is the way Steve recommends. You sign in once. There is no API key to create or keep safe.

<Callout type="warning" title="You need a paid Claude plan">
  Pro, Max, Team or Enterprise. Free Claude accounts cannot add connectors yet. On Team or Enterprise, an owner has to turn connectors on first.
</Callout>

<Steps>
  <Step title="Open Connectors">In the **Claude desktop app**: **Settings → Connectors**. On **claude.ai** in a browser: **Settings → Customize → Connectors**.</Step>
  <Step title="Add a custom connector">Click **Add custom connector**.</Step>
  <Step title="Name it and paste the address">Use any name. Steve is fine. If you already have a connector with that name, choose another. Paste `https://app.hiresteve.ai/api/agent/mcp` as the remote MCP server. Leave **Client ID** and **Client Secret** empty. You do not need them.</Step>
  <Step title="Accept the warning">Claude warns that this is an unverified third-party connector. That is expected for any connector Anthropic did not build.</Step>
  <Step title="Approve in the browser">A browser window opens. Sign in to Steve if asked. It can open in a different browser than the one you are using. Pick your organization and click **Approve**.</Step>
  <Step title="Allow the tools">Steve has 47 tools, and Claude asks permission for each one. Choose **Always allow** the first time.</Step>
</Steps>
