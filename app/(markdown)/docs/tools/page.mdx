You never call these tools yourself. You ask in plain words, and your assistant picks the right tool. This page lists all 47 so you know what is possible.

- **Reads** only looks things up. Nothing changes in Steve.
- **Changes** saves something, starts a background job, or publishes a link.
- Tools that draft something first (their names start with `prepare_`) save nothing. They are counted as changes for rate limits only.

<Callout type="note" title="Plans and limits">
  Battle cards and website tracking are not in the entry MCP plan. After a trial ends, every tool that changes something stops working. Reads keep working. See [Plans and limits](/docs/account/plans-and-limits).
</Callout>
