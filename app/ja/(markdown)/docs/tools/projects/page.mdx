プロジェクトは、自社と、追跡する競合のまとまりです。これらのツールで、自社の Web サイトからプロジェクトを作成し、既存のプロジェクトを一覧表示できます。その後は、Steve が自動で市場の調査を始めます。

## こんなふうに頼んでみましょう

<Prompt lang="ja">Steve にあるプロジェクトを教えて。</Prompt>
<Prompt lang="ja">acme.com の Steve を設定して。</Prompt>
<Prompt lang="ja">うちの会社 https://www.klue.com で競合分析のプロジェクトを作って。</Prompt>
<Prompt lang="ja">はい、作成してください。</Prompt>

## 流れ

<Steps>
  <Step title="下書き">自社の Web サイトを伝えます。アシスタントがサイトを読み取り、下書きを作ります。この時点では何も保存されません。</Step>
  <Step title="下書きを確認">アシスタントが、名前、業界、ターゲット市場、説明を表示します。間違いがあれば修正します。</Step>
  <Step title="作成">「はい」と答えると、プロジェクトが作成され、競合の調査が始まります。最初の競合は数分で表示されます。</Step>
</Steps>

## プロジェクトを一覧表示する

<ToolBadge name="list_projects" bucket="read" lang="ja" />

組織内のすべてのプロジェクトを表示します。各プロジェクトの業界、説明、競合数も確認できます。

<Facts>
  <Fact label="指定できること">表示する件数（最大 100 件、既定は 20 件）。</Fact>
  <Fact label="取得できる内容">組織名と、競合数付きの各プロジェクト。</Fact>
</Facts>

まだプロジェクトがない場合は、アシスタントが設定を提案します。ほかのツールは、ここで指定したプロジェクトを使います。

## 会社の Web サイトからプロジェクトの下書きを作る

<ToolBadge name="prepare_create_project" bucket="read" lang="ja" />

会社の Web サイトを 1 件読み取り、プロジェクトの下書きを作ります。何も保存しません。少し時間がかかります。

<Facts>
  <Fact label="指定できること">会社の Web サイト（形式は問いません）。任意で、下書きの方向づけになるヒント。</Fact>
  <Fact label="取得できる内容">名前、業界、サブ業界、ターゲット市場、説明、自社名、Web サイトを含む下書き。</Fact>
</Facts>

結果は次の 3 つのいずれかです。
- **準備完了**：下書きが完成しています。
- **入力が必要**：足りない情報があります。アシスタントが入力をお願いします。
- **選択が必要**：サイトに複数の製品があります。プロジェクトの対象にする製品を選びます。

<Callout type="note">
  example.com のようなプレースホルダーのサイトは受け付けられません。下書きは何も保存しませんが、1 時間あたりの変更の上限には含まれます。トライアル終了後は使えません。
</Callout>

## プロジェクトを作成する

<ToolBadge name="create_project" bucket="write" lang="ja" />

プロジェクトと、その中の自社を作成します。続いて、競合の調査と、自社の調査（レビュー、ニュース、企業情報、Web サイトのページ）をキューに入れます。

<Facts>
  <Fact label="指定できること">名前、業界、サブ業界、ターゲット市場、説明、自社名、実際の Web サイト。</Fact>
  <Fact label="任意">更新の頻度（隔週、毎週、毎月、手動。既定は手動）。SEO、広告、ソーシャル、Web サイトの追跡をオンにするかどうか。</Fact>
  <Fact label="取得できる内容">作成されたプロジェクトと自社のレコード。調査がキューに入ったかどうかも返ります。</Fact>
</Facts>

<Callout type="warning" title="上限">
  MCP のエントリープランでは、プロジェクトは 1 つです。プランの上限を超えると、Steve は上限のメッセージとともに拒否します。自社はすでに追加されているため、競合として重ねて追加しないでください。
</Callout>
