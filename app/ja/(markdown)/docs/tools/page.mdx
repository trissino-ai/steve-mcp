ツールを自分で呼び出す必要はありません。ふだんの言葉で頼めば、アシスタントが適切なツールを選びます。このページでは 47 個すべてを紹介します。できることの全体像をつかめます。

- **読み取り** は情報を調べるだけです。Steve の内容は変わりません。
- **変更** は、何かを保存する、バックグラウンドの処理を始める、リンクを公開する操作です。
- 先に下書きを作るツール（名前が `prepare_` で始まるもの）は、何も保存しません。レート制限の上でのみ、変更として数えられます。

<Callout type="note" title="プランと上限">
  バトルカードと Web サイトの追跡は、MCP のエントリープランには含まれません。トライアルが終了すると、変更を行うツールはすべて使えなくなります。読み取りは引き続き使えます。詳しくは [プランと上限](/ja/docs/account/plans-and-limits) をご覧ください。
</Callout>
