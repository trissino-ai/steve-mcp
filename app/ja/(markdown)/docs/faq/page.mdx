## どのアシスタントが使えますか？

Claude（デスクトップと Web）、Claude Code、ChatGPT、Cursor、VS Code です。Steve が独自のガイドを用意しているのは、Claude と Claude Code です。ほかのアシスタントは、それぞれの最新の手順に従います。詳しくは[アシスタントを接続](/ja/docs/connect/claude)をご覧ください。

## アドレスは何ですか？

`https://app.hiresteve.ai/api/agent/mcp` です。MCP Streamable HTTP を使います。

## API キーは必要ですか？

いいえ。Steve アカウントでサインインします。クライアント ID とシークレットは空のままにします。

## 接続は読み取り専用ですか？

いいえ。アシスタントは、あなたとして組織の Steve データを読み書きできます。Steve には読み取りと書き込みのスコープがありますが、強制はされません。

## 組織が Signals 組織でも使えますか？

いいえ。Signals 組織は接続できません。

## 回答が空なのはなぜですか？

Steve がまだ収集中の可能性があります。何も見つからなかった、その競合を追跡していない、またはプランにその情報源が含まれていない場合もあります。詳しくは[Steve の答え方](/ja/docs/getting-started/how-it-works)をご覧ください。

## データはどのくらい新しいですか？

Steve はリアルタイムではなく、スケジュールに沿って収集します。新しい競合のデータは、数分から数時間で入ります。MCP プランでは、データは週 1 回更新されます。

## Steve は記憶で答えますか？

いいえ。アシスタントは、Steve が収集したデータを使い、出典と日付を示すよう指示されています。

## アシスタントが勝手に公開することはありますか？

確認なしに公開することはありません。レポート、キャンバス、バトルカードは、公開リンクに同意するまで非公開です。リンクはいつでも取り下げられます。

## 組織を切り替えるには？

もう一度接続し、別の組織を選びます。

## 接続を解除するには？

Steve で接続を取り消します。詳しくは[サインインと権限](/ja/docs/account/sign-in)をご覧ください。

## 料金はいくらですか？

MCP プランは月額 $49 で、3 日間のトライアルがあります。詳しくは[プランと上限](/ja/docs/account/plans-and-limits)をご覧ください。
