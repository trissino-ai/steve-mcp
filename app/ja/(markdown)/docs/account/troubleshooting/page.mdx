Steve のエラーには、短いコード、メッセージ、ヒントが表示されます。下の表でコードを探してください。アシスタントに「もう一度試して」と頼むだけで、原因が解消することも多くあります。

## 接続とサインイン

| コード | 意味 | 対処 |
|---|---|---|
| missing_token | アシスタントがサインイン情報を送っていません。 | Steve をもう一度接続します。 |
| invalid_token | Steve がこのサインイン情報を認識できないか、別のアドレス向けに作られたものです。組織が Signals 組織の可能性もあります。 | アシスタントで Steve を削除し、追加し直します。Signals 組織は接続できません。 |
| token_expired | 1 時間のアクセスが終了しました。 | ほとんどのアシスタントは自動で更新します。更新されない場合は、接続し直します。 |
| grant_revoked | 接続が取り消されました。 | もう一度接続します。 |
| refresh_expired | 60 日間 Steve を使っていません。 | もう一度接続します。 |
| refresh_reused | 古いサインインキーが再度使われました。Steve は安全のため接続を取り消しました。 | もう一度接続します。 |
| refresh_race | 2 つの更新が同時に行われました。 | もう一度試します。 |
| org_membership_lost | あなたはもうその組織に所属していません。 | もう一度接続し、所属している組織を選びます。 |

サインインの手続きに関するエラー（invalid_client、invalid_redirect、invalid_request、pkce_mismatch、state_mismatch、handoff_invalid、handoff_expired など）の場合は、アシスタントで Steve を削除し、追加し直して、最初からやり直します。承認ページに **そのアプリケーションは登録されていません** や **その戻り先は許可されていません** と表示された場合も、同じ手順です。何も承認されていません。

<Callout type="tip" title="ブラウザが別の場所で開きましたか？">
  承認ページは、アシスタントとは別のブラウザで開くことがあります。そちらでサインインしてください。「アプリケーションに戻ります」と表示されたら、タブを閉じて構いません。
</Callout>

## プランと上限

| コード | 意味 | 対処 |
|---|---|---|
| feature_not_granted | お使いのプランにこの機能は含まれていません。 | 再試行しないでください。支払いページでアップグレードするか、契約を管理している担当者に相談します。 |
| limit_reached | プロジェクトや追跡する SNS アカウントなどの上限に達しました。 | 何かを削除するか、アップグレードします。 |
| trial_expired | トライアルが終了しました。読み取りはできますが、保存はできません。 | 支払いページでお申し込みください。 |
| rate_limited | 1 時間または 1 日の利用枠を使い切りました。 | メッセージに表示されたリセット時刻まで待ちます。接続し直してもリセットされません。 |
| manager_only | 組織のマネージャーだけが行える操作です（キャンバスの作成や共有）。 | マネージャーに依頼します。 |

## リクエストの内容

| コード | 意味 | 対処 |
|---|---|---|
| validation_failed | 入力に誤りがあります。example.com のような仮の Web サイト、すでに追跡中の競合、競合のサイトにないページなどです。 | メッセージを読み、その入力を直します。 |
| project_not_found | 接続した組織に、その名前のプロジェクトがありません。 | Steve にプロジェクトの一覧を表示してもらいます。 |
| competitor_not_found | プロジェクト内に、そのような追跡中の競合がありません。 | Steve に競合の一覧を表示してもらいます。 |
| account_not_found | そのような SNS アカウントがありません。 | Steve に追跡中のアカウントの一覧を表示してもらいます。 |
| platform_mismatch | 別のプラットフォームのリンクが指定されました。 | 正しいプラットフォームのリンクを使います。 |
| handle_not_recognized | Steve がプロフィールとして読み取れませんでした。 | プロフィールの完全なリンクを貼り付けます。 |
| tracking_request_not_found | そのような Web サイトのトラッカーがありません。 | Steve に Web サイトのトラッカーの一覧を表示してもらいます。 |
| battle_card_not_found | そのようなバトルカードがありません。 | Steve にバトルカードの一覧を表示してもらいます。 |
| report_not_found | そのようなレポートがありません。 | 実行したレポートから始めます。 |
| template_not_found | そのようなレポートテンプレートがありません。 | Steve にレポートテンプレートの一覧を表示してもらいます。 |
| template_empty | テンプレートにセクションがありません。 | Steve アプリでセクションを追加します。 |
| survey_not_found | このプロジェクトに、そのサーベイがありません。 | どのサーベイか指定します。 |
| canvas_not_found | その競合のキャンバスがまだありません。 | キャンバスの状況を確認するか、作成を依頼します。 |
| canvas_exists | キャンバスがすでにあります。 | 置き換えてよいかどうかを伝えます。 |
| no_anchor | プロジェクトに自社が登録されていません。 | 基準となる自社を追加します。 |
| not_publishable | レポートまたはキャンバスが未完成です。 | 完了するまで待ってから共有します。 |

## Steve 側の問題

| コード | 意味 | 対処 |
|---|---|---|
| upstream_failed | 内部の処理が失敗しました。 | もう一度試します。 |
| server_error | Steve が回答を完了できませんでした。 | もう一度試します。Steve アプリでも同じデータを確認できます。 |
| queue_send_failed | Steve がバックグラウンドのジョブを開始できませんでした。何もキューに入っていません。 | しばらくしてから、もう一度試します。 |
| config_missing | Steve のサービスが設定されていません。 | ご自身では解決できません。Steve サポートにお問い合わせください。 |

## よくある問題

- **ツールの結果が空です。** 収集には数分から数時間かかります。[Steve の答え方](/ja/docs/getting-started/how-it-works)をご覧ください。
- **Claude にコネクタを追加できません。** Pro、Max、Team、Enterprise のいずれかが必要です。Team と Enterprise では、オーナーが有効にする必要があります。
- **許可の確認が多すぎます。** Steve のツールに **Always allow** を選びます。
