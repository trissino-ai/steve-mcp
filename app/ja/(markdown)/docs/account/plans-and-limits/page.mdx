Steve MCP でできることは、Steve のプランによって決まります。Steve は質問ごとの課金はしません。1 時間あたり、1 日あたりにできる操作の量を制限します。

## MCP プラン

MCP プランは、アシスタントの中で Steve を使うためのプランです。料金は**月額 $49** です。

<Facts>
  <Fact label="ユーザー">1 ユーザー</Fact>
  <Fact label="プロジェクト">1 プロジェクト</Fact>
  <Fact label="競合">3 社</Fact>
  <Fact label="含まれるもの">競合ニュース、インテリジェンスキャンバス、LinkedIn・X・Instagram のアクティビティ、Google と Meta の広告追跡</Fact>
  <Fact label="含まれないもの">バトルカード、Web サイト追跡、レビューサイト、レポート</Fact>
  <Fact label="更新頻度">毎日ではなく週 1 回</Fact>
</Facts>

ほかのプランには、競合数の増加など、別の上限があります。内容は、組織のプランによって決まります。Steve の[料金ページ](https://app.hiresteve.ai/payments)をご覧ください。

## トライアル

- MCP プランのトライアルは、カード登録なしで **3 日間**です。ほかのプランは 14 日間から始まります。
- トライアル中は、残り日数が Steve から通知されます。
- トライアルが終わると、Steve は**保存や開始を伴う操作をすべてブロック**します。読み取りは引き続き使えます。
- 次のメッセージが表示されます。"Hey, your trial has expired. Please subscribe to use further."（トライアルの期限が切れました。続けて使うにはお申し込みください。）Steve の支払いページでお申し込みのうえ、もう一度お試しください。
- ここでは、下書きの手順も保存として扱われるため、同じように止まります。

## プランに含まれない機能

一部のツールは、お使いのプランにない機能を必要とします。

| 機能 | 影響を受けるツール | 表示される内容 |
|---|---|---|
| バトルカード | バトルカードの 6 つのツール | 「組織で有効になっていません」というメッセージ |
| Web サイト追跡 | Web サイト追跡の 6 つのツール | 同じメッセージ。Web サイトの変更の読み取りは、空の結果が返ります。 |
| Google または Meta 広告 | 広告のツール | 情報源が有効でないという短い注記。エラーではありません。 |
| レポート | レポートのツール | 実行できるテンプレートがないことが多い |
| レビューサイト | レビュー | 結果が空になることが多い |

アシスタントには、再試行しないよう指示されています。セルフサービスのプランでは、支払いページでアップグレードしてください。マネージドプランでは、Steve の契約を管理している担当者に相談してください。

<Callout type="note" title="プランは個別に設定される場合があります">
  組織によっては、手動で設定されています。その場合、一覧が異なることがあります。ツールが有効でないと表示されたら、Steve の担当者に確認してください。
</Callout>

## プランの上限

プロジェクト、競合、追跡する SNS アカウントの数が上限に達することがあります。その場合、Steve は `limit_reached` と伝えます。何かを削除するか、アップグレードしてください。

## レート制限

制限は、毎時の開始時刻（UTC）にリセットされます。

| 制限 | 回数 |
|---|---|
| 読み取り（ニュース、一覧、状況） | 1 時間あたり 300 回 |
| 書き込み（保存、ジョブの開始） | 1 時間あたり 60 回 |
| レポート | 1 時間あたり 5 回まで開始可能。各テンプレートは 1 日 3 回まで。 |
| キャンバス | 1 時間あたり 5 回まで作成可能 |
| バトルカードの書き直し | 1 時間あたり 10 回 |
| 競合の検索 | 1 時間あたり 5 回。プロジェクトごとに 1 日 1 回。 |

- 下書きの手順（「準備」のツール）は**書き込み**の制限を使います。ただし、レポートの確認は読み取りの制限を使います。
- 制限は、接続ごと**および**すべての接続を合わせた個人ごとに数えられます。新しく接続し直しても、リセットされません。
- 拒否された実行や、開始されなかった実行は、1 日の上限に数えられません。
- 制限に達すると、Steve がリセットされる時刻を伝えます。
