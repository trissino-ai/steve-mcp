Steve は接続時に、アシスタントの振る舞い方を伝えます。このページでは、そのルールを分かりやすく説明します。

## 回答は収集したデータに基づきます

アシスタントは、競合について自分の記憶で答えてはいけません。Steve のツールを呼び出します。Steve がまだデータを収集していない場合は、アシスタントがそう伝えます。

すべての項目に**出典リンク**と**日付**が付きます。アシスタントはその両方を表示するはずです。表示されない場合は「これはどこの情報ですか？」と聞いてください。

<Prompt lang="ja">Klue の最新ニュースは何ですか？ 各項目に出典と日付を付けてください。</Prompt>

## 次のステップの提案

ほとんどの回答のあとに、Steve は最大 3 つの次のステップを提案します。提案は質問の形で書かれています。アシスタントは最初の 1 つをあなたに尋ね、返事を待ちます。

提案されたステップを、アシスタントが勝手に実行することはありません。主導権は常にあなたにあります。

## 下書き、確認、保存

何かを保存するとき、Steve は 2 段階で進めます。

<Steps>
  <Step title="準備">Steve が Web サイトを読み取るか、リクエストを確認して、下書きを表示します。この時点では何も保存されません。</Step>
  <Step title="確認">下書きを読み、必要なら修正して、「はい」と答えます。</Step>
  <Step title="書き込み">ここで初めて、アシスタントがプロジェクト、競合、トラッカー、レポートを保存します。</Step>
</Steps>

これは、プロジェクトの作成、競合の追加、Web ページの追跡、レポートの実行に当てはまります。

<Callout type="note" title="決まりごとであり、ロックではありません">
  下書きの手順は、アシスタントへの指示として定められた進め方です。Steve のサーバーが強制するものではありません。保存される内容は、必ず確認してください。
</Callout>

## 空の結果の意味

空の一覧は、必ずしも「何も起きなかった」という意味ではありません。Steve は理由を伝えます。よくある理由は次のとおりです。

| 理由 | 意味 | 対処 |
|---|---|---|
| 収集中 | Steve が最初の収集をまだ終えていません。 | しばらく待って、もう一度聞きます。 |
| 見つからなかった | このフィルターや期間では、Steve が何も見つけられませんでした。 | 期間やフィルターを広げます。 |
| 未追跡 | この競合またはアカウントをまだ追跡していません。 | Steve に追跡の開始を頼みます。 |
| プランに含まれない | お使いのプランにこの情報源が含まれていません。 | [プランと上限](/ja/docs/account/plans-and-limits)をご覧ください。 |

## 収集には時間がかかります

Steve は Web をリアルタイムで見ているわけではありません。スケジュールに沿って収集します。

- 競合を追加すると、最初のデータは**数分から数時間**後に届きます。
- 通常、最初に埋まるのはニュースです。
- MCP プランでは、データの更新は毎日ではなく週 1 回です。
- 長い処理（レポート、キャンバス、競合の検索）はバックグラウンドで実行されます。アシスタントが開始し、あとで状況を確認します。
